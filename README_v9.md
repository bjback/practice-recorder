# Practice Recorder v9

Changes:
- iPhone file pickers now explicitly accept common audio extensions including MP3, M4A, AAC, WAV, AIFF, OGG, WebM, and MP4 audio.
- Added a **Record from** slider so recording can begin anywhere in the sing-against track.
- Compare now aligns the recorded excerpt with the same musical position in the reference track.
- Replay and Stop return to the excerpt's recording-start position.
- Retains Pause/Resume, playback-position slider, live volume controls, and remembered timing correction.
- Also fixes missing comparison-state variable declarations in the uploaded v8 file.

For GitHub Pages, replace the existing `index.html` with this file and commit.
